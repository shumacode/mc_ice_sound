# 模组介绍

## 功能

这是一个基于Fabric的Minecraft模组。

它将 Minecraft 中冰块、浮冰、蓝冰的放置、破坏、踩踏音效，替换成了震撼！美味！（突发恶疾）的“冰冰冰”雷霆音效。

<img width="544" height="544" alt="冰冰冰" src="https://github.com/user-attachments/assets/12914d76-1a8b-4987-824d-281b6f6a7494" />

安装Mod menu mod后，可以对该模组的音效进行配置。
